# Conversaciones

Las conversaciones serán completamente escritas a mano, no generadas automáticamente.

El jugador podrá elegir respuestas, pero:

- Las respuestas no modifican la historia principal.
- Únicamente cambian el humor y la personalidad del protagonista.
- No existirán árboles narrativos complejos.

Regla de desarrollo asociada: los diálogos deben estar separados de la lógica (ver [DevPrinciples.md](../Technical/DevPrinciples.md)).
