# Principios de desarrollo

Durante todo el proyecto deben respetarse estas reglas:

1. Priorizar terminar el juego antes que añadir sistemas complejos.
2. Todos los sistemas deben ser reutilizables (diálogos, logros, misiones, interacción).
3. El código debe estar modularizado.
4. Los diálogos deben estar separados de la lógica.
5. El McClarens debe sentirse vivo mediante pequeños detalles (música, partículas, animaciones, NPCs).
6. La exploración debe recompensarse con referencias y logros.
7. La prioridad es crear una experiencia divertida y memorable, no un juego técnicamente complejo.
