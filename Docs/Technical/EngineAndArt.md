# Motor

- **Motor elegido:** Unity 6
- **Lenguaje:** C#

Proyecto completamente en 2D con perspectiva cenital ligeramente inclinada (estilo RPG moderno, no pixel art).

El escenario estará construido mediante:

- Tilemaps
- Objetos independientes
- Capas
- Partículas
- Luces

Nunca mediante una única imagen de fondo.

# Tipo de juego

**Género:** aventura narrativa, exploración, humor, puzles, minijuegos.

- No es un RPG.
- No existen niveles.
- No existe combate.
- No existe experiencia.

La progresión es completamente narrativa (ver [Story.md](../GameDesign/Story.md)).
